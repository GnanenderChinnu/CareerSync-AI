# Exam Content Plan

## AptiReady Test

Purpose: Aptitude readiness for IT fresher screening.

Topics:

- Quantitative aptitude
- Logical reasoning
- Verbal ability
- Workplace problem solving

Materials:

- Number systems and percentages
- Logical patterns and arrangements
- Reading comprehension basics

## CodeStart Test

Purpose: Basic coding readiness.

Topics:

- Variables
- Loops
- Arrays
- Strings
- Functions

Materials:

- Programming flow and syntax
- Arrays and strings drills
- Function-based problem solving

## CodePro Test

Purpose: Advanced coding readiness.

Topics:

- Complexity
- Recursion
- Stacks and queues
- Trees
- Dynamic programming

Materials:

- Big O and optimization patterns
- Stacks, queues, and tree traversal
- Dynamic programming starter set
